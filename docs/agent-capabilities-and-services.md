# 智能体能力、连接与运行

本文为当前能力与操作说明，核对日期：2026-10-25；源码基线：`e4f1974`。适用于 Apple 芯片 Mac。文末另列 2026-10-18 的历史验收范围，本次文档核对未重新调用真实模型、业务服务或 Docker 引擎。

## 创建时会怎样沟通

NEUMA 根据任务了解输入规模、处理精度、交付标准、工作过程、资料保存与外部条件。简单且明确的任务可以很快确认；会改变实现方式的问题会继续澄清。无需自己选择编程语言、数据库或框架。

在主对话中确认需求且通过校验后，系统先保存需求，再自动打开对应智能体开始制作；无需再次手动保存或点击生成。制作失败会保留需求和实际进度，尚未成功交付的新智能体不会显示为可用。完整流程见 [使用指南](user-guide.md)。

已经上传的材料会优先由系统测量。尚未确定的信息可以给大致范围，或通过样例、结果提纲来校准。没有说需要历史记录，不会自动解释成不需要；没有说材料大小，也不会直接按小任务设计。

需求侧栏保留简短进度，“具体任务要求”可以展开查看。正式设计发现新的关键取舍时，点击“继续澄清需求”，在原智能体上补充；已运行的旧版本不会因此被自动删除。

## 配置已有服务

在智能体设置中打开“连接与模型”。这里根据该智能体的实际需要列出知识库、业务服务或专属模型等连接，不要求每个智能体都配置外部服务。

1. 根据服务要求填写地址、选择资源或登录授权。
2. 密钥填写在专用输入框，不放进聊天、需求说明或生成代码。
3. 保存后可以测试允许的只读操作，或者发现该服务提供的工具和资源。
4. 完成配置后回到原来的智能体继续工作。

“已配置，尚未验证”表示资料已经保存，不代表业务功能成功。“已验证”需要真实调用结果。没有无副作用测试方式的服务，会在你正常授权的任务中进行首次验证，不为测试而擅自发送、删除或修改数据。

官方 MCP 也遵守服务本身的访问权限。你没有权限读取的资料，不能靠换接口或抓取绕过。系统会区分尚未授权、缺少适配、需要开发和当前无法支持，并说明可行替代方式。

## 管理专属功能

打开设置中的“运行与接口”，可以查看运行环境和专属功能状态。

- **JavaScript / Python**：由架构根据任务选择。Python 首次需要时准备受管环境，不要求你安装或配置系统 Python。
- **Docker（可选）**：仅在对应方案需要容器时使用，需要本机已安装并启动 Docker。普通功能不以 Docker 为前提。
- **启动、停止、重新启动**：管理这个智能体已交付的服务。停止时即使本机服务记录保存失败，仍尝试终止全部匹配进程，并显示实际错误；修复存储问题后可再次停止，确认停止记录已保存。没有专属服务时页面会明确说明。
- **运行记录**：按需查看，不在需求侧栏显示整段内部报告。
- **交付版本**：查看历史并恢复可用版本。数据格式变化时先备份，在副本上转换和核验后再切换。若新版已经写入新数据，系统会阻止直接覆盖为旧备份。

服务在当前电脑运行。关闭网页后 NEUMA 后端仍可继续工作；退出后端或关机后停止。重启保留任务检查点；需要继续时按界面提示处理。

主对话、制作和研发也支持已接受任务的后台续看；重新打开后查看原任务，明确停止绑定当前执行编号。流程等待补充时，填写表单继续。上次操作可能已产生外部结果时，先核实：已完成就提供实际结果；确实需要重新执行时，明确选择重试。表单绑定当前任务版本及执行尝试，旧窗口不能替另一次尝试确认结果；记录与预算保留。不要在无法判断结果时反复提交。

## 给其他本机工具调用

接口默认关闭。在“给本机其他工具使用”中选择允许调用的功能，再开启接口。NEUMA 提供 API/MCP 地址和访问令牌；调用方仍受所选动作、授权范围和交付版本限制。

令牌只在生成当次显示，离开面板后清空。按需复制给调用方，不公开分享。停用接口会撤销后续访问。这里提供本机回环入口，不包含公网发布或云端部署。

调用方还可分页读取该授权任务已登记的产物快照；不能用接口读取任意本机路径。配置、动作调用与产物读取说明见 [连接与接口指南](connections-guide.md)。

## 验证范围与历史证据

架构评审后的修订，以及新研发批次中的计划、任务和整体验收修复，支持按问题归属动态安排独立子 Agent。分组提案由程序合并并检查版本与修改范围，之后继续完整验收与独立评审；各组提交本身不构成业务通过证据。旧记录仍按原协议恢复，额度与恢复约束见[架构说明](../ARCHITECTURE.md)和[研发设计](development-layer-design.md)。

自动化测试使用本机模拟模型和模拟业务服务，检查需求、协议、保存、隔离、恢复和界面行为；不使用你的真实业务账号做测试。模拟连接成功不证明真实数据检索质量，代码运行通过也不证明浏览器视觉效果。

2026-10-18 的验收曾在 Apple 芯片 Mac 上实际执行 Node 和受管 Python 程序，检查分批流程、暂停继续、进程隔离、数据迁移和版本回退；内置浏览器检查了需求创建和配置入口。具体证据见 [当日交付记录](history/three-stage-implementation-2026-10-18.md)。这份记录只证明当时执行过的检查，其中源码布局与测试数量已成为历史，不代表后续版本自动取得相同验收。

Docker 路径具备程序实现与模拟控制检查；上述历史验收未覆盖真实 Docker 引擎，本次文档核对也未重新检查引擎状态。需要 Docker 的交付仍必须通过实际环境检查和执行验收后才能宣布可用。尚未支持的环境或能力会明确阻止相应操作，不自动降低需求或回退到无隔离执行。
