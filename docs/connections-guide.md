# NEUMA 连接配置与验证

本文为当前连接与本机接口说明，核对日期：2026-10-25；源码基线：`e4f1974`。适用于 Apple 芯片 Mac；本次核对未使用真实业务账户，具体服务是否可用仍以该服务的授权和实际调用结果为准。

连接是智能体访问外部服务的入口。数据库、知识库和业务系统均通过已设计的 HTTP API 或 MCP 连接使用；不会自动安装数据库驱动，也不会因发现某个工具就授权执行它。

## 配置流程

1. 在智能体设置的“连接与模型”中打开架构要求的连接卡片。
2. 填写服务地址，并选择匿名、访问令牌、请求头密钥、账号密码或登录授权。
3. 登录授权使用服务商页面。完成后返回 NEUMA，点击“刷新连接状态”。需要客户端注册的服务填写官方客户端编号；支持公开客户端动态注册的服务可以自动注册。
4. MCP 点击“发现工具与资源”；HTTP 可以导入 OpenAPI 3 JSON。资源选择项由已经评审的只读操作读取，选择完成后保存。
5. 点击“测试连接”。只有明确定义为无副作用的操作会执行测试；只读 POST 检索也支持。没有安全测试接口时显示“已配置，尚未验证”，正常任务的真实调用成功后再记录验证状态。

配置表单只使用平台支持的字段，不执行外部说明或模型生成的脚本。没有未保存修改时，“刷新连接状态”同步最新配置；已有草稿时保留输入及其原始版本，其他窗口已更新的配置会阻止旧草稿保存。可以点击“放弃修改并刷新”丢弃本机草稿、清空凭据输入并读取最新配置。切换智能体和迟到请求不会覆盖未保存的输入；成功保存后清空本次已提交的凭据输入，保存期间的新输入继续保留。

当前运行版本与已经通过评审的新方案分别显示。新方案初次查看继承当前配置，但修改和清除只作用于该候选配置；正式激活后才切换活动指针。任务保存启动时的配置方案，版本回退可以恢复旧指针。当前活动授权被撤销后，继承同一授权的历史方案也不能继续使用它。

## HTTP 与 MCP 支持范围

HTTP 操作绑定已评审的请求方法、相对路径模板和输入输出格式。查询参数、请求头、JSON、表单和文件上传可以按定义映射。文件上传仅通过宿主提供的当前任务材料或产物引用读取，不接受任意本地路径。服务地址与认证目标不能被运行参数覆盖，带凭据请求不跟随重定向。

MCP 使用官方 TypeScript SDK v2 的 Streamable HTTP，支持工具发现、工具调用、资源目录和固定资源读取。只有架构列出的工具或资源能够调用。工具的输入输出契约变化会停止对应操作；再次发现仅记录待核验信息，仍需更新评审后的定义。第三方任意 stdio 命令不会被自动安装执行。

OpenAPI 导入产生候选操作，不直接改变智能体权限。支持文档内部引用；远端引用和循环引用需要提供独立操作说明。

## 授权与凭据

登录采用授权码、PKCE 和独立本机回调，核对回调地址、状态、服务商身份及连接版本。初始化期间取消、断开登录请求或关闭连接池同样终止本次授权，迟到的发现响应和回调不能继续提交凭据。没有云端中转。服务商必须支持本机原生应用或公开客户端；需要其他认证方案的服务保留待接入状态，不会伪造授权成功。

macOS 钥匙串保存主密钥，具体凭据保存在每个智能体的私有加密仓库中。业务配置只保存引用。旧明文连接在首次使用或更新时迁移；钥匙串不可用或保存失败时停止操作并保留原配置。凭据不返回页面、模型和生成代码，也不进入交付快照。

撤销连接会立即阻止旧任务继续调用。登录换账号或授权范围收紧会增加授权版本；刷新响应省略 scope 时保留已有授权范围，正常令牌刷新不会无故使任务失效。外部操作已经完成后发生本地状态保存失败时，不会自动重复发送操作。

## 大结果与作用范围

JSON 结果超过 128 KiB 时保存为私有结果引用，可按分页读取；单次接收最多 20 MiB。结果绑定智能体、连接以及私聊或具体群任务范围，其他范围不能读取。运行中不会把结果引用当作文件路径使用。

## 实现入口和测试

- `AgentConnectionStore` 提供 `call`、`test`、`discover`、`authorize`、授权状态/取消、`readResult` 和 `close`，实现位于 [agent-connections.mts](../src/agents/agent-connections.mts)。
- HTTP、MCP、OAuth、凭据仓库与设计契约位于 `src/connections/`。
- [连接协议测试](../test/services/connections-protocols.test.mts)通过显式的 `credentialKeySource` 提供固定测试密钥，不访问真实钥匙串；OAuth 与 MCP 使用本机模拟服务。它们覆盖只读 POST、授权、凭据、发现与配置版本等协议行为，不证明正式业务账户的权限或数据检索质量。

## 把已交付动作提供给本机其他应用

“运行与接口”中可以选择允许外部调用的动作，并显式启用接口。每个智能体使用独立回环端口，默认不开启；接口令牌只显示一次，磁盘仅保存摘要。重新发布会更换授权，旧令牌立即失效。

REST 入口提供动作列表、任务提交、任务列表、任务状态、取消及已登记产物的分页读取。提交和读取都绑定交付版本；提交必须使用稳定的 `mutationId`，相同请求编号不会重复执行。接口只能查看这次授权创建的任务，不能读取普通聊天或其他授权的任务。

MCP 与 REST 使用同一动作和任务控制器。MCP 中每个公开动作使用 `run_<动作编号>` 工具，并提供 `get_task`、`cancel_task` 和 `read_artifact`。长任务先返回任务编号，再读取进度和结果；产物只读取该授权任务登记的不可变快照，按返回的 `nextOffset` 继续读取 base64 字节并核对完整 `sha256` 与 `size`，不接受任意文件路径。接口与读取边界见 [service-gateway.mts](../src/services/service-gateway.mts) 和 [网关测试](../test/services/service-gateway.test.mts)。

支持 HTTP MCP 的客户端直接使用设置页地址。只接受 stdio 的客户端可使用设置页返回的 NEUMA 本地桥接配置，将接口令牌填入客户端私有环境变量 `NEUMA_MCP_TOKEN`；令牌不放入启动参数。桥接只连接 NEUMA 的本机回环地址，使用官方 MCP SDK，不执行第三方服务命令。

重启时恢复原端口。端口被其他程序占用时明确显示失败，不静默换地址。服务随 NEUMA 后端关闭，关闭网页不会关闭接口；升级交付版本后需要重新选择并发布动作，旧客户端不能静默执行新版动作。
